# Google Form registration integration

Synchronization is not active until the Google Form, linked Google Sheet, Apps Script trigger, backend secret, and program form key are configured.

## Backend configuration

1. Generate a long random secret outside source control.
2. Set `DJANGO_APPS_SCRIPT_SECRET` in the backend environment. Never commit the value.
3. In Sidrah CMS, open the target Training Program and set a unique **External Form Key**.
4. Set the program registration URL and open/closed state.

## Google Form and linked Sheet

1. Create the public Google Form. It must not require respondents to sign in.
2. Link responses to a Google Sheet from the Form **Responses** tab.
3. Use these question/column headings, or update `COLUMN_MAP` in the script to match exactly:

| Script field | Default Sheet heading | Required |
|---|---|---|
| `timestamp` | `Timestamp` | Generated by Google |
| `full_name` | `Full Name` | Yes |
| `email` | `Email` | Yes |
| `phone` | `Phone` | No |
| `national_id` | `National ID` | No |
| `college_or_school` | `College or School` | No |
| `academic_year` | `Academic Year` | No |
| `preferred_language` | `Preferred Language` | No (`en` default) |
| `notes` | `Notes` | No |

The script derives a stable retry-safe submission ID from the spreadsheet, response row, and timestamp. The backend also enforces idempotency.

## Apps Script setup

1. Open the **linked response Sheet**, then **Extensions → Apps Script**.
2. Paste `apps_script_training_registration.gs` into the project.
3. In **Project Settings → Script Properties**, add:
   - `BACKEND_URL`: the complete backend endpoint ending in `/api/v1/training/apps-script/submission/`
   - `APPS_SCRIPT_SECRET`: the same secret configured in the backend environment
   - `FORM_KEY`: the target Program's External Form Key
4. Do not put the secret directly in script source.

## Install the Sheet trigger

1. Open **Triggers** in Apps Script and choose **Add Trigger**.
2. Function: `onFormSubmit`
3. Event source: **From spreadsheet**
4. Event type: **On form submit**
5. Authorize and save.

Submit a non-production test response and confirm it appears under **CMS → Training Registrations** with the correct course before opening registration publicly.

## Operational notes

- The script retries transient/network failures and HTTP 408/429 responses.
- Re-delivery is safe because `external_submission_id` is idempotent.
- Client validation/authentication failures are not retried indefinitely.
- The script does not log student names, email addresses, phone numbers, national IDs, form responses, or the integration secret.
- One script project maps to one Program through `FORM_KEY`. For multiple forms, configure each linked Sheet separately.
